TIPS PENGISIAN
═══════════════════════════════════════════════════════════════

1. GUNAKAN SELESAI
   - Ketik "SELESAI" (uppercase) untuk mengakhiri input bagian
   - Tekan Enter setelah SELESAI

2. STRUCTUR KONTEN
   Latar Belakang: 500-800 kata
   Rumusan Masalah: 3-5 pertanyaan
   Tujuan: 3-5 tujuan spesifik
   Pembahasan: 800-1200 kata dengan argumen
   Kesimpulan: 300-500 kata

3. TIPS PENULISAN
   - Gunakan bahasa formal
   - Hindari slang/gaul
   - Gunakan struktur paragraf yang jelas
   - Berikan contoh konkret jika diperlukan

═══════════════════════════════════════════════════════════════

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

1. ERROR "Module not found"
   Jalankan: pip install -r requirements.txt

2. ERROR "Template tidak ditemukan"
   Pastikan file .docx ada di folder templates/

3. ERROR saat input
   - Pastikan mengetik "SELESAI" untuk mengakhiri
   - Jangan tekan Ctrl+C kecuali mau keluar

4. ERROR saat generate dokumen
   - Pastikan folder output/ ada dan bisa ditulis
   - Cek disk space yang tersedia
